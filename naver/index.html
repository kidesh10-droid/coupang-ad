네이버 광고 장부는 이카운트 매출·이익과 네이버 광고 리포트를 합쳐서, 품목별로 광고비와 배송비까지 뺀 진짜 순이익과 ROAS를 계산하고 무엇을 바꿔야 할지 알려주는 공용 장부입니다.

  1. 파일 올리기: 업로드 탭에 이카운트·네이버 리포트 엑셀을 끌어다 놓으면 끝. 종류와 기간은 자동으로 알아봅니다.
  2. 확인: 대시보드(이번 달) → 주간(주차별 품목 표) → 주간·월간 분석(판단과 할 일)
  3. 조치: 분석 탭의 '긴급' 항목부터 네이버 광고센터에 반영(목표 ROAS, 제외 키워드, 예산)
  4. 공유: 저장은 자동. 같은 주소(dnd-coupang.pages.dev/ad/)로 들어오는 모든 사람·기기에 같은 자료가 보입니다.

계산 기준: 순이익 = 이카운트 매출이익 − 배송비(개당 배송비 × 판매수량) − 광고비 · 광고 전환은 네이버 '총 판매수량'(14일, 설정에서 1일로 변경 가능)

3. 분석 읽는 법

  • 손익분기 ROAS: 광고로 판 만큼 이익이 광고비와 같아지는 ROAS. 이보다 낮으면 광고가 손해입니다. (배송비를 뺀 마진으로 계산)
  • 권장 목표 ROAS = 손익분기 × 1.3 (여유 30%). 네이버 캠페인 목표 ROAS를 이 값 근처로 맞추세요.
  • 판단: 확대 손익분기보다 크게 높음 · 유지 · 손익분기 아래 · 손실 · 선택 필요 광고가 적자를 키움 — 재고 소진·손실 감수·예산 축소와 대안·구조 개선·광고 끄기 중 상황에 맞게 고르도록 숫자와 함께 보여줌 · 전략 · 손실 감수 손해 봐도 파는 품목
  • 광고로 이익 내기 어려운 구조: 배송비 뺀 마진이 너무 작아(예: 3~4%) 손익분기 ROAS가 1,500%를 넘는 품목. 목표 ROAS로는 해결이 안 되니 가격·원가·배송비를 보거나, 꼭 팔아야 하면 전략 품목으로 지정하세요.
  • 전략 품목: 분석 탭 '전략 품목 · 손실 감수' 표에서 지정하고 월 손실 한도를 넣으면, 한도 안에서 쓸 수 있는 광고비나 줄일 일 예산을 계산해 줍니다.
  • 키워드: '전환 0건' = 광고비만 쓰고 판매 0. 화면에는 당장 대응할 대표 15개만, 전체는 엑셀. 자사 키워드는 제외 말고 입찰가만 낮추세요.
  • '예상 효과' 금액은 지금 효율이 유지된다고 가정한 추정치입니다.

4. 직접 입력 · 엑셀 다운로드

  • 흰 칸·노란 칸은 직접 입력, 회색 칸은 자동 계산입니다. Enter = 아래 칸.
  • 입력값: 매출액·판매수량·매출이익·개당 배송비·광고비·목표 ROAS 등 원자료만 넣으면 ROAS·순이익·개당 값은 수식으로 계산됩니다.
  • 마이너스(적자)는 어디서든 빨간색입니다.
  • 엑셀 다운로드: 표 제목 오른쪽 버튼 = 그 표만, 탭 맨 위 '이 탭 표 전체 엑셀' = 탭의 모든 표(표마다 시트), 주간 탭 '모든 주차 엑셀' = 주차별 시트. 서식(머리글 색·테두리·합계·음수 빨강·숫자 서식)이 들어간 채로 받아집니다.

5. 저장 · 공유 · 권한

이전 버전 되돌리기, 자료 삭제, 설정 변경 등 관리자 권한이 필요한 일은 관리자에게 요청하세요.

  • 저장은 자동입니다. 오른쪽 위 글자가 '저장 중…' → '공용 저장소 · 팀 공유 중'이면 완료. 동기화 버튼은 필요 없습니다.
  • 다른 기기는 창을 다시 누르거나 1분이 지나면 새 자료를 가져옵니다. 바로 보려면 새로고침.
  • 화면 맨 위에 노란 '새 버전이 올라왔습니다' 띠가 뜨면 꼭 새로고침하세요. 이전 버전 화면으로 올리면 결과가 다를 수 있습니다.
  • 입력·수정은 누구나, 삭제는 관리자만 (삭제 버튼을 누르면 관리자 비밀번호를 묻습니다).
  • 버전 기록(설정 탭, 관리자): 파일 업로드·삭제 직전 상태는 항상, 수정 중에는 10분 간격으로 30일 동안 보관. '이 시점으로 복구'로 되돌리고, 복구도 다시 되돌릴 수 있습니다.
  • 칸을 비우거나 0으로 바꾸는 건 '수정'이라 막히지 않습니다. 실수했으면 버전 기록으로 되돌리세요.

6. 회의록

  • 회의록 탭 → '새 회의록 폴더 만들기'(이름 + 비밀번호). 폴더마다 비밀번호가 따로이고, 내용은 이 기기에서 암호화된 뒤 저장되어 관리자도 볼 수 없습니다.
  • 비밀번호를 잊으면 아무도 되살릴 수 없습니다. 따로 적어 두세요.
  • 대표 관리자는 누구의 회의록 폴더든 삭제(초기화)할 수 있습니다. 단, 내용은 암호화되어 있어 관리자도 열어 볼 수는 없습니다. 비밀번호를 잊었다면 관리자에게 폴더 삭제를 요청한 뒤 새로 만드세요.
  • + 메모 = 메모장, + 표 = 엑셀처럼 수식(=SUM(B2:B10), =B2*C2, =ROUND(C2/B2*100,1), =IF(…)). 수식을 치다가 다른 칸을 누르면 그 칸 주소가 들어가고, Shift+클릭은 범위입니다. 한/영이 한글이어도 됩니다.
  • 30분 동안 안 쓰면 자동으로 잠깁니다.

7. 자주 묻는 것

이럴 때이렇게
올렸는데 숫자가 안 바뀜Ctrl+Shift+R(강력 새로고침) 후 다시 올리기. 노란 '새 버전' 띠가 떴는지 확인.
주간 표에 매출액·판매수량이 비어 있음같은 기간(예: 11/12~11/18)으로 조회한 이카운트 파일을 올리기.
광고가 엉뚱한 품목에 붙음품목·배송비 탭에서 이름 연결·합산 그룹 확인. 계속되면 알려주세요.
배송비가 0원으로 계산됨품목·배송비 탭에서 개당 배송비 입력(대시보드에 '배송비 미입력' 개수 표시).
전환 판매가 주문 건수로 보임그 리포트를 다시 올리면 '총 판매수량'으로 바뀝니다.
잘못 올리거나 지웠음관리자에게 요청 → 설정 → 버전 기록 → '파일 업로드 직전' 시점 복구.

분석 기준

실이익 = 이카운트 매출이익 − 광고비 − 배송비(개당 배송비 × 판매수량). 부가세를 켜면 광고비를 네이버에 실제 결제하는 금액 기준으로 뺍니다.
